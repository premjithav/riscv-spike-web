$ spike loading 
Fetching and compiling spike-web.wasm (7.9 MB)…

Programs print through HTIF: Spike's front-end server catches tohost writes and proxies write() to this console. ISA tests print nothing on success; a failure reports *** FAILED *** (tohost = N), where N >> 1 is the failing test case. Benchmarks report tohost = 1337 when they take an unexpected trap; try mm on the rv64imac hart, which has no FPU.

This build passes 109 of 109 rv64u{i,m,a,f,d,c} tests and produces instruction traces identical to native Spike. Uploaded ELFs must be bare-metal programs linked at 0x80000000 that exit through tohost; Linux binaries need a proxy kernel, which is not included.
